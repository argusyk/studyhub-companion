# Агент перевірки лабораторних звітів – каркас для ЛР12

`checker.py` – детермінований прототип без виклику моделі: місце, де ваш агент (Agent SDK)
замінить правила. Він отримує ЛИШЕ текст звіту (без прав запису, без персональних даних).
`cases/` + `expected.json` – eval-набір із п'яти випадків; `run_eval.py` порівнює вердикти.
Запуск: `python -m pytest agents` або `python agents/checker/run_eval.py`.
