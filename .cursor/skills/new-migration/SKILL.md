# Нова міграція

1. Змінити ORM-модель у apps/api/app/models/.
2. Створити ревізію: `alembic revision --autogenerate -m "<опис>"`.
3. Відкрити згенерований файл і перевірити його вручну: автогенерація пропускає
   перейменування й зміни типів.
4. Додати downgrade, що точно скасовує upgrade.
5. Застосувати на локальній БД: `alembic upgrade head`, потім `alembic downgrade -1`
   і знову `upgrade head`.
6. Додати або оновити тест (apps/api/tests/test_migrations.py).
7. У описі PR вказати, чи міграція зворотна та чи потребує вона заповнення даних.

Не запускай міграції на спільній БД. Уже злиті ревізії не редагуй.
