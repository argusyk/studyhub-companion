# Баг-репорт: «Запізно» для здач перед дедлайном (ЛР9)

**Симптом.** Студенти здають роботи о 21:00–23:59 за Києвом, за хвилини до дедлайну,
а StudyHub записує `is_late = true` і показує «Запізно». У базі значення збережене (не кеш).

**Умови.** Продакшн-сервер працює в `Europe/Kyiv`; у CI часовий пояс UTC, тест зелений.
Тиждень після переходу на літній час (29.03.2026) здається гіршим, бо різниця з UTC зросла з 2 до 3 год.

**Відтворення.** `python scripts/repro_deadline_bug.py` (імітує сервер у Києві змінною
SERVER_TZ) або тест `test_not_late_one_minute_before_deadline_on_kyiv_server` (xfail).

**Завдання.** Знайти кореневу причину (не симптом), виправити, додати регресійний тест,
який падає без виправлення. Заборонено послаблювати наявні тести.
