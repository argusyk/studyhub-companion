# Макет дашборда викладача (ЛР8)

Файл `dashboard-mockup.svg` – макет із токенами в `<desc>`. Його можна відкрити в браузері
або імпортувати в Figma (File -> Place image). Для Design Mode потрібен запущений застосунок
(`npm run dev`). Дані для екрана: `packages/shared/src/dashboard.example.json`.

Вимоги до реалізації: токени замість «магічних» значень, доступні кольори (контраст),
підписи для скрінрідерів, статуси не лише кольором, а й текстом.
