# Відмінності legacy та нової реалізації (ЛР10)

| Правило | Legacy (фактично) | Нова реалізація | Рішення |
|---|---|---|---|
| R-07 штраф | 10 % за кожен ПОВНИЙ день (`timedelta.days`); після 5 днів не приймається (`final = null`) | 10 % за кожну КАЛЕНДАРНУ добу за Києвом, стеля 30 %, приймається завжди | Свідома зміна політики (затверджує зав. кафедри, [дата]) |

| Часовий пояс | naive-дати без поясу | aware, зберігання в UTC | Виправлення дефекту |
| Ін'єкції | SQL конкатенацією | параметризовані запити SQLAlchemy | Виправлення дефекту |
| Шлях API | `/api/groups/<g>/grades` | `/api/v1/groups/{group}/grades` | Канонічний префікс |
