# Задача A: імпорт оцінок із Moodle (worktree 1)

Прочитати CSV-експорт журналу оцінок Moodle і повернути оцінки за email студента.
**Зона файлів (інші задачі сюди не заходять):**
`apps/api/app/integrations/moodle/**`, `apps/api/tests/moodle/**`.
Не змінювати `main.py`, моделі й чужі модулі. Формат: роздільник `;`, перший рядок – заголовок
(`Email;ЛР1;ЛР2;…`), порожнє значення = немає оцінки. Дані тільки вигадані.
Приймання: тест на коректний файл, порожню клітинку, некоректне число, зайві колонки.
