# Задача C: сповіщення про дедлайн (worktree 3)

Чиста функція, що формує текст нагадування студенту про дедлайн лабораторної
(за часом кафедри Europe/Kyiv) і вирішує, кому слати (хто ще не здав).
**Зона файлів:** `apps/api/app/notifications/**`, `apps/api/tests/notif/**`.
Надсилання пошти/месенджера НЕ реалізовувати: лише формування повідомлень (`list[Message]`).
Приймання: тест для літнього/зимового часу, для студента, що вже здав, і для порожнього списку.
