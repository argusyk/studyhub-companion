# legacy/ – старий прототип StudyHub (Flask) для ЛР10

Це навмисно «поганий» прототип, який студенти перенесуть на FastAPI. Його НЕ можна
використовувати як приклад стилю: у коді залишено типові запахи (див. нижче).
Дані вигадані. Запуск тестів з КОРЕНЯ репозиторію:

    pip install -r legacy/requirements.txt
    python -m pytest legacy/tests

## Ендпоінти (поточна, фактична поведінка)
- `GET /api/groups/<group>/grades` – оцінки групи
- `GET /api/groups/<group>/stats` – статистика групи
- `GET /api/submissions/<id>/score` – підсумковий бал здачі

## Запахи, які ви маєте знайти (не виправляйте їх у legacy/)
глобальне з'єднання з БД; SQL, зібраний конкатенацією (SQL-ін'єкція); `print`-налагодження;
«голий» `except`; магічні числа; усе в `utils.py`; копіпаст між ендпоінтами; naive-дати
без часового поясу; прихована політика штрафів і округлення.

## Фікстури
`legacy/tests/fixtures/group_ki21.json` – вхідні дані; `ki21_golden.json` – фактична
відповідь старого коду (знімок). Перегенерація знімка: `python legacy/tools/make_golden.py`.
